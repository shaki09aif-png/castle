# Рыцарский замок XIII века на холме

Школьный проект по истории: подробная 3D-модель западноевропейского рыцарского замка
XIII века на вершине холма. Работает в браузере, построена на **Three.js**.
Всё создаётся кодом: нет скачанных 3D-моделей и готовых текстур — камень, трава,
скала, земля, дорога и вода рисуются процедурно на `<canvas>` и в шейдерах.

## Как запустить

Нужен [Node.js](https://nodejs.org/) версии 20.19 или новее.

```bash
npm install     # один раз: установить Three.js и Vite
npm run dev     # запустить локальный сервер
```

Затем открыть в браузере адрес, который покажет Vite (обычно http://localhost:5173/).
После открытия несколько секунд генерируются рельеф и текстуры.

Собрать статическую версию (папка `dist/`, её можно открыть через любой веб-сервер):

```bash
npm run build
npm run preview
```

## Управление

- **Левая кнопка мыши** — вращение камеры вокруг замка
- **Колесо мыши** — приближение и отдаление (можно подлететь вплотную к любой детали)
- **Правая кнопка мыши** — сдвиг камеры
- Камера не опускается под землю.

### Этап 1 — что сделано

- **Холм** высотой ~84 м: крутые верхние склоны со скальными выходами и слоистыми
  уступами породы, лощины, стекающие вниз по склону, пологое подножие.
- **Площадка на вершине** неправильной вытянутой формы — по её краю пройдут стены.
  Северо-западная часть чуть выше: там будет донжон.
- **Терраса перед воротами** (с юга) и **сухой ров**, вырубленный в скале поперёк неё,
  со ступенчатыми неровными стенками.
- **Дорога-серпантин** с четырьмя шпильками от террасы к подножию и к реке.
  Там, где полотно на насыпи (особенно на поворотах), стоят **подпорные стенки**
  из бутового камня.
- **Валуны и скальные глыбы** (InstancedMesh) — больше у вершины, меньше внизу.
- **Река** у подножия с песчаными берегами и рябью на воде.
- **Небо** с солнцем и облаками (шейдер), **дымка** на горизонте,
  **дальние холмы** с пятнами лесов.
- Мягкие тени от солнца и рассеянный свет неба (карта окружения).

## Устройство кода

```
index.html          страница, экран загрузки, подсказки
src/main.js         рендерер, камера, управление, главный цикл
src/layout.js       общая планировка: форма вершины, ворота, ров, река
src/terrain.js      холм, скалы, ров, дорога, подпорные стенки, река
src/lighting.js     небо с облаками, солнце, тени, дымка, окружающий свет
src/textures.js     процедурные текстуры (трава, скала, земля, дорога, кладка, вода)
src/materials.js    общие материалы (трипланарное текстурирование)
src/noise.js        генераторы шума и случайных чисел
```

Модули `walls.js`, `towers.js`, `gate.js`, `keep.js`, `courtyard.js`, `details.js`
появятся на следующих этапах.

Сцена детерминирована: все «случайности» берутся из генераторов с фиксированным
зерном, поэтому при каждом запуске замок выглядит одинаково.
