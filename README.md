# Рыцарский замок XIII века на холме

Школьный проект по истории: подробная 3D-модель западноевропейского рыцарского замка
XIII века на вершине холма. Работает в браузере, построена на **Three.js**.

Геометрия — холм, дорога, река, стены, деревья, трава — создаётся кодом.
Текстуры по умолчанию тоже процедурные (рисуются программой), но проект умеет
подключать фотореалистичные бесплатные CC0-материалы с **Poly Haven** (см. ниже).

## Сайт

Замок можно открыть прямо в браузере: **https://shaki09aif-png.github.io/castle/**

Сайт обновляется сам: при каждом обновлении ветки `main` GitHub Actions
собирает проект (`vite build`) и публикует его на GitHub Pages
(файл `.github/workflows/deploy.yml`). Чтобы это заработало, один раз нужно
включить Pages в настройках репозитория: **Settings → Pages → Build and deployment →
Source: GitHub Actions**.

## Как запустить у себя

Нужен [Node.js](https://nodejs.org/) версии 20.19 или новее.

```bash
npm install     # один раз: установить Three.js, Vite и библиотеки постобработки
npm run dev     # запустить локальный сервер
```

Открыть в браузере адрес, который покажет Vite (обычно http://localhost:5173/).
Около 5 секунд уходит на генерацию рельефа, текстур и растительности.

Собрать статическую версию (папка `dist/`, её можно открыть через любой веб-сервер):

```bash
npm run build
npm run preview
```

### Фотореалистичные текстуры Poly Haven (рекомендуется)

```bash
npm run assets
```

Скрипт `scripts/download-assets.mjs` скачивает с [polyhaven.com](https://polyhaven.com)
PBR-текстуры (цвет, нормали, шероховатость, ambient occlusion) и HDRI неба в папку
`public/assets/` и записывает `public/assets/manifest.json` со списком файлов и авторов.
После этого достаточно перезагрузить страницу. Если какого-то файла нет,
вместо него используется процедурная текстура — сцена всё равно работает.

Скачать можно и вручную: для каждого набора положить файлы
`color.jpg`, `normal.jpg` (карта «nor_gl»), `roughness.jpg`, `ao.jpg` в папку
`public/assets/textures/<набор>/` и описать их в `manifest.json`
(формат — как создаёт скрипт). Наборы: `wallStone`, `rubbleStone`, `rock`, `grass`,
`dirt`, `gravel`, `wood`, `roof`, `cobble`; HDRI неба — `public/assets/hdri/sky.hdr`.

### Качество графики

Уровень задаётся параметром адреса: `?quality=low`, `?quality=medium` (по умолчанию)
или `?quality=high`, например `http://localhost:5173/?quality=high`.
Кроме того, работает динамическое разрешение, как в играх: если частота кадров
падает ниже 32 FPS, внутреннее разрешение немного снижается, а при запасе
возвращается обратно. Текущий FPS показан в правом верхнем углу.

## Управление

Два режима камеры, переключение — клавиша **F**.

**Орбита** (при запуске):
- **Левая кнопка мыши** — вращение вокруг замка
- **Колесо мыши** — приближение и отдаление
- **Правая кнопка мыши** — сдвиг камеры

**Свободный полёт:**
- **Клик** по экрану — захватить мышь, **Esc** — отпустить
- **W A S D** — движение (вперёд — туда, куда смотрите), **мышь** — обзор
- **Пробел** — вверх, **C** или **Ctrl** — вниз
- **Shift** — ускорение в 4 раза, **колесо мыши** — скорость полёта (1–250 м/с)

Камера не опускается под землю. **H** — скрыть или показать подсказку в углу,
счётчик FPS — в правом верхнем углу.
Совет: для спуска удобнее **C** — сочетание Ctrl+W браузер понимает как «закрыть вкладку».

### Этап 1 — холм и окружение

- **Холм** высотой ~84 м. Шум разных масштабов с искажением координат даёт
  неровные лопасти и отроги склонов, уступы и пояса скальных выходов, отдельные промоины.
  Под скальными поясами — **осыпи** из мелких камней.
- **Вершина** неправильной формы (~110 × 75 м) с пологими перепадами высоты,
  плавным «плечом» при переходе в склоны и **выходами коренной породы по краю**.
  Самая высокая точка — северо-запад, там будет донжон.
- **Терраса перед воротами** и **ров**, вырубленный в скале, с неровными стенками.
  По просьбе заказчика ров заполнен водой; чтобы вода не уходила на склон,
  его торцы перекрыты земляными дамбами.
- **Дорога-серпантин** с пятью шпильками и **подпорными стенками** из бутового камня.
- **Извилистая река** переменной ширины с неровными берегами: крутые обрывчики
  на внешних сторонах излучин и галечные пляжи на внутренних, камни в воде и у берега.
- **Смешивание материалов** по крутизне и высоте: на крутых склонах — скала,
  на пологих — трава, у дороги — утоптанная земля, у воды и под скалами — галька.
  Скалы и крутые поверхности текстурируются **трипланарно** (без растяжения).

### Этап 2 — крепостные стены

- Стена толщиной 2,4 м повторяет контур вершины; изломы — там, где край вершины
  отходит от прямой. В узлах оставлены места для 6 башен (этап 3) и проём под
  надвратную башню (этап 4).
- Кладка из **отдельных камней разного размера и оттенка** (PBR: цвет, нормали,
  шероховатость, AO), лёгкие неровности поверхности, **скошенный цоколь**,
  **мох и сырость у основания**, потёки.
- **Зубцы** с покрывающими камнями; в каждом втором зубце — **бойница**-щель
  насквозь. Бойницы есть и в теле стены.
- **Боевой ход**: деревянный настил на балках с подкосами, **перила** со стороны двора.
- **Хурды** — деревянные галереи на консольных балках снаружи северных стен.
- **Каменные лестницы** со двора на боевой ход.

### Этап 3 — башни

- **Шесть башен** в узлах стены: четыре круглые и две квадратные, разного диаметра
  (7,4–10 м) и высоты (верхняя площадка на 6–10 м выше боевого хода стены).
  Башни вынесены наружу от линии стены, чтобы простреливать её вдоль (фланкирование).
- Кладка со **скошенным цоколем** снаружи (со стороны двора стена вертикальная),
  каменный **поясок** под парапетом, у трёх башен парапет вынесен на **ступенчатых консолях**.
- **Зубчатый парапет** под крышей; в каждом втором зубце — бойница-щель.
- **Бойницы на нескольких ярусах**, обращённые наружу; часть — **крестообразные**,
  характерные для XIII века.
- **Конические** (у круглых) и **шатровые** (у квадратных) крыши из плоской
  черепицы «бобровый хвост». **Ряды черепицы видны отдельно**: каждый ряд в геометрии
  чуть выступает над предыдущим, плитки разного оттенка, с лишайником.
  Снизу, через проёмы между зубцами, видна дощатая обшивка крыши и пол площадки.
- **Флюгеры**: шпиль, позолоченный шар, крест и вымпел, который поворачивается от ветра.
- **Двери** со стрельчатой аркой из клинчатых камней, из досок, с железными полосами,
  петлями, гвоздями и кольцом-ручкой: одна со двора, по одной с каждого боевого хода.
- **Окна со ставнями** (двойное окно со средником) на жилом ярусе со стороны двора.

### Этап 4 — ворота и барбакан

- **Надвратная башня** стоит на линии стены над проёмом и выходит лицом ко рву.
  Сквозной **проезд** со стрельчатыми арками и стрельчатым **сводом**, мостовая
  из каменных плит, в своде — «отверстия-убийцы» (для защиты проезда сверху).
- **Ниша для поднятого моста** на фасаде; над ней — отверстия, в которые уходят **цепи**.
- **Подъёмный мост** из дубовых досок на продольных брусьях, с железной оковкой и
  осью-шарниром у порога; опущен и лежит на **каменном устое** посреди рва.
  Дальше до барбакана — **неподвижный деревянный мост на козлах** с перилами.
  **Цепи** собраны из отдельных звеньев и немного провисают.
- **Опускная решётка (герса)** из дубовых брусьев с железными накладками и
  коваными остриями внизу; приподнята, ходит в пазах в стенах проезда.
- **Дубовые ворота** из двух створок с железными полосами, гвоздями, петлями,
  раскосами и кольцами; распахнуты внутрь.
- **Машикули**: парапет наверху вынесен на мощных консолях, между консолями —
  отверстия в полу, через которые защитники могли бросать камни на штурмующих.
- **Вода во рву** — `Water` с отражениями (как в реке).
- **Барбакан** — укреплённый двор перед рвом: стены с зубцами и каменным боевым
  ходом, ворота со стрельчатой аркой и створками, две круглые **башенки** с
  коническими крышами на южных углах, деревянная лестница на стену.
  Дорога от серпантина проходит через ворота барбакана, по мосту и через надвратную башню во двор.

### Этап 5 — донжон

- **Донжон** — главная башня, последнее убежище при осаде. Стоит в самой высокой
  точке двора у северо-западной стены: квадратный, 14 × 14 м, **пять этажей**,
  боевая площадка на высоте 30 м, с флагом — около 42 м над двором.
- **Вход поднят на второй этаж** (около 6,5 м над землёй): к нему ведёт деревянная
  лестница с площадкой на столбах. При осаде лестницу можно было разобрать или сжечь.
  Первый этаж — кладовая без входа снаружи.
- Этажи: 1 — кладовая (только узкие щели), 2 — входной, 3 — зал с парным окном,
  4 — жилые покои с окнами на две стороны, 5 — караульный ярус с крестообразными бойницами.
- **Угловые лопатки** (плоские контрфорсы), **каменные пояса** на уровне перекрытий,
  **скошенный цоколь** со всех сторон.
- Наверху — **зубчатый парапет на консолях** и четыре угловые **башенки-бартизаны**
  с коническими крышами на ступенчатых каменных консолях.
- **Уборная (гардероб)**, вынесенная на консолях на задней стене, с отверстием вниз;
  **дымовая труба** камина на боковой стене.
- **Флаг с гербом** (золотой замок на красном поле) на флагштоке с растяжками;
  ткань колышется на ветру прямо в шейдере видеокарты, флаг разворачивается по ветру.

### Этап 6 — внутренний двор

Постройки стоят вдоль крепостных стен, как было принято, — середина двора
свободна для людей, телег и учений. Между задними стенами построек и крепостной
стеной оставлен проход под деревянным боевым ходом. Лестницы на стены (по одной
на каждую сторону) подобраны так, чтобы не упираться в постройки.

- **Большой зал** (17 × 10,5 м) у восточной стены: пол поднят над двором, к двери
  ведут каменные ступени; высокая крутая черепичная крыша; на фасаде контрфорсы и
  **витражные** стрельчатые окна, большие витражи во фронтонах; на коньке —
  **дымник-фонарь** над центральным очагом, из него тянется дымок.
- **Часовня** стоит алтарём на восток (как было принято): три витража в алтарной
  стене, каменный крест на фронтоне, контрфорсы, **колокольня** у западного торца
  с открытой звонницей, бронзовым колоколом на дубовой балке и шатровой крышей с крестом.
- **Кухня** рядом с залом: большой очаг и **каменная труба** на торце, **дым**,
  поленница у стены.
- **Колодец** в центре двора: каменный сруб, вода внизу, **ворот** с рукоятью и
  намотанной верёвкой, **ведро** на краю, двускатная крыша из дранки.
- **Конюшня** — деревянный навес: четыре **стойла** с перегородками, ясли с сеном,
  солома на полу, поилка; рядом стог сена и **телега с сеном**.
- **Кузница** — открытый навес: каменный **горн** с тлеющими углями (светится и
  освещает кузницу, свет мерцает), вытяжной колпак и труба с дымом, мехи,
  **наковальня** на пне с молотом, инструменты на стене.
- **Казармы** — каменные, с односкатной крышей, две двери, окна со ставнями,
  **стойки с копьями** у входа.
- **Склад** (деревянный, с двустворчатыми воротами) и **амбар** на каменных
  опорах (защита зерна от мышей и сырости) с деревянными ступенями.
- **Мелочи**: бочки с железными обручами, ящики, две телеги со спицевыми колёсами,
  стог сена, стойки с копьями, **стрельбище** с тремя соломенными мишенями
  (в мишенях торчат стрелы).
- **Мощение**: булыжные дорожки от ворот к колодцу и от колодца ко всем дверям,
  площадь вокруг колодца; края мостовой неровные, камни «выпадают» в землю.
  Остальной двор — утоптанная земля с травой.

### Этап 7 — деревня, мелкие детали, люди

**Деревня у подножия**
- **Деревянный мост** через реку: настил из досок на продольных прогонах, опоры
  из свай с насадками и подкосами, перила, каменные устои на берегах.
- **Крестьянские дома** вдоль дороги за мостом: каменный цоколь, **фахверк**
  (деревянный каркас со стойками, ригелями и раскосами), стены из глиняной обмазки
  с побелкой, **соломенные крыши** с толщиной и связанным коньком, двери, окна со
  ставнями; из части труб идёт дымок.
- За домами — **огороды за плетнями** (колья с переплетёнными прутьями) с грядками
  капусты, лука и гороха; стога, бочки, телега.
- **Водяная мельница** на берегу выше моста: каменный дом, соломенная крыша,
  деревянный жёлоб и **колесо, которое вращается**.
- **Поля узкими полосами** — так пахали при средневековой трёхпольной системе:
  пашня с бороздами, всходы рядами, спелая пшеница, пар; межи между полосами,
  стога на сжатых полосах.

**Двор замка стал живее**
- **Люди** (около 45 фигур): стража в шапелях (железных касках с полями) с копьями
  и щитами на стенах и у ворот, лучники у стрельбища и на стенах, кузнец у наковальни,
  священник у часовни, рыцарь в сюрко и знатный гость у зала, слуги, женщина с
  ведром у колодца, дети; в деревне — крестьяне у домов, в огородах и на мосту.
  Одежда соответствует XIII веку: туники, шоссы, капюшоны, платья с покрывалом.
- **Старая липа** посреди двора со скамьёй вокруг ствола.
- **Шатры-павильоны** в красно-белую и сине-белую полоску с фестонами, растяжками
  и вымпелами.
- **Курятник** на ножках с лесенкой, загон из плетня и куры (и во дворе тоже).
- **Квинтана** — учебный столб с вращающейся перекладиной (щит и мешок с песком),
  столбы для отработки ударов мечом.
- **Огород** с грядками за плетнём, **стол на козлах** с лавками, кувшином и мисками,
  **мешки** с зерном у склада и амбара, **дрова** у кузницы, **коновязь** у конюшни.
- **Плющ** на внутренних сторонах стен и на донжоне.

### Графика

- **PBR-материалы** (MeshStandardMaterial) с картами нормалей, шероховатости и AO везде.
- Рельеф: четыре слоя в текстурных массивах, трипланарная проекция, смешивание
  с учётом «высоты» текстуры (камни проступают сквозь траву).
- **HDRI** как источник окружающего освещения; небо — HDRI Poly Haven (если скачана)
  или процедурное с облаками.
- **Мягкие тени** (PCF) высокого разрешения; теневая область следует за камерой
  и сжимается при приближении, поэтому вблизи тени чёткие.
- **Объёмный высотный туман** с подсветкой в сторону солнца, дымка на горизонте.
- **Постобработка**: SSAO (N8AO), лучи солнца (god rays), bloom, тональная
  компрессия ACES, цветокоррекция, виньетка, сглаживание SMAA/MSAA.
- **Трава** — десятки тысяч пучков через инстансинг прямо на видеокарте, с ветром.
- **Деревья**: дуб, бук, берёза, сосна и кусты, с двумя уровнями детализации;
  листва колышется на ветру и просвечивает на солнце. Густота убывает к вершине.
- **Вода** в реке — `Water` из three/examples: отражения и волны.

| Текстуры и HDRI неба, скачиваемые `npm run assets` (список ассетов и авторов — в `public/assets/manifest.json` после скачивания) | [Poly Haven](https://polyhaven.com) | CC0 |

| [Vite](https://vite.dev) — сервер разработки и сборка | npm | MIT |
